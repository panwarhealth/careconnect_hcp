# Gated clinical content is excluded from search via meta robots (pages) and
# X-Robots-Tag headers (uploaded documents). Uploads are deliberately NOT
# disallowed here: crawlers must be able to fetch a file to see its noindex
# header, and a disallow would leave already-known URLs indexable as URL-only.
